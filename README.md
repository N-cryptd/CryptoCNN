# CryptoCNN

## Project Overview

CryptoCNN is an experimental project to explore the application of Convolutional Neural Networks (CNNs) for cryptocurrency price prediction. 

This project investigates the feasibility of using candlestick chart images, enhanced with technical indicators, as input features for a CNN model. The aim is to classify short-term price movements, specifically predicting 'BUY' or 'SELL' signals for cryptocurrencies listed on Binance.

This project is primarily exploratory, focused on understanding the potential of CNNs in this domain without predefined performance targets or constraints.
